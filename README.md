# 📱 Realistic WhatsApp Chat Screenshot Generator 💬

---

📱 A web-based tool to generate realistic WhatsApp-style chat screenshots.  
💬 You can customize chat details like contact name status message bubbles delivery ticks battery level and network indicators with a live preview.

🎨 The UI is designed in:
- 🟢 WhatsApp Green Theme
- ⚪ Clean White Layout
- 📱 Realistic WhatsApp Design

✅ Exactly like the real WhatsApp application.

---

# 🔧 Tech Stack

- ⚛️ React
- 🎨 Tailwind CSS
- ⚡ JavaScript ES6+

---

# ✨ Features

## 📱 Operator & Phone Customization

👤 Users can customize:

- 📶 Operator Name
- 🕒 Phone Time
- 👤 Contact Name
- 🟢 Contact Status
  - 🟢 online
  - ⌨️ typing...
  - 🕓 last seen

⚡ Everything appears live inside the phone preview.

### 📌 Example

```txt
📶 Operator Name: vodafone
🕒 Phone Time: 9:41 AM
👤 Contact Name: Johnny Doe
🟢 Contact Status: online
```
